# Spider Stats

Spider Stats is a free, fan-made VALORANT companion website. It uses plain HTML, CSS, and JavaScript, so GitHub Pages can host it without a server.

## Preview it on your computer

1. Install Python if it is not already available.
2. Open this folder in File Explorer. Click the folder address bar, type `powershell`, and press Enter.
3. Type `py run_app.py` and press Enter. If that does not work, try `python run_app.py`.
4. Keep the black window open while you use the preview at `http://127.0.0.1:8000`.

## Publish for free with GitHub Pages

1. Make a new **public** repository on GitHub. GitHub Pages on the free plan requires the repository to be public.
2. Put the contents of this folder into the repository. GitHub Desktop is the easiest way to upload this many image files: choose **Add an Existing Repository** if you already made one, or **Create a New Repository**, then publish it to GitHub.
3. On GitHub, open the repository's **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish and use the site link shown in Settings > Pages.
6. To update it later, make changes in this folder, commit them in GitHub Desktop, and push them to GitHub. GitHub Pages publishes the newest version from the same repository.

The repository and website are public, so people can see the source files. They cannot change your copy unless you give them write access. Do not add passwords, login cookies, or private keys to this repository.

## What is included

- Agent profiles, lore, abilities, and locally bundled portraits.
- Map guides, callouts, five-Agent example compositions with portraits, and an ability pin board for personal planning.
- Competitive basics and a manually entered match tracker.
- Separate cosmetic collections for weapon skins, skin colour variants, gun buddies, sprays, Flex items, player cards, and bundles. Items can be checked off and expanded in your inventory.
- Patch summaries, Alpha and Omega lore, and a creator page.
- Installable-web-app support for compatible browsers.

## Notes

- Collection marks, map pins, and match entries are stored in the current browser on the current device. They do not sync across devices or connect to a Riot account.
- Map ability pins are your own planning notes, not verified lineup instructions.
- Patch and game content must be reviewed and updated as VALORANT changes; the website does not update itself.
